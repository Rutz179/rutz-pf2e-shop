# Rutz's PF2e Shop

Free Lite edition · [Plus on Patreon](https://www.patreon.com/Rutz179) · [Discord](https://discord.gg/pnVW5QmXKx)

A JRPG-style shop window, and a shop editor that takes a minute to stock.

- **Buy & sell** — categories, search, quantities, exact change in coins, chat trade log. Shops are plain loot actors.
- **Easy stocking** — templates (smith, alchemist, general store …) scaled to your party's level (read from the Party actor), wealth levels with funds from the treasure-by-level table, random fill, roll tables, restocking every N days, your own prices for anything.
- **Repairs** at the counter.
- **Plus** — special orders (players order what isn't on the shelf; it arrives in a few days), rune forge (etch and transfer by the rules), precious-material smithing, animals that become minions, formulas for sale, price events (festivals, shortages), the shop ledger and an inventory log.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/rutz-pf2e-shop/releases/latest/download/module.json
```
Foundry VTT v13–v14 · PF2e · English / 한국어

The *Shops* button above the Actors tab, double-clicking a shop actor, or `game.rutzShop.open("name")`.
